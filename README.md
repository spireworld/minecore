# MineCore Launcher

Лаунчер Minecraft Java Edition для Windows. C# · .NET 10 · WPF · MVVM · SQLite.

**Поточний стан: етап 1 з 8** — архітектура, інсталятор, головне вікно, реальний список версій.
Запуск гри, встановлення версій, авторизація, моди й модпаки з'являться на наступних етапах.

> Код етапу 1 написаний без компіляції (середовище, де він створювався, не має Windows і .NET SDK).
> Перша збірка на Windows може показати кілька помилок компіляції — надішліть їх, і я виправлю.

## Вимоги для збірки

- Windows 10 (1809) або Windows 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Visual Studio 2022 17.13+ (необов'язково)

## Інструкція зі складання

```powershell
cd MineCore
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт робить три кроки: публікує лаунчер (self-contained, один файл), пакує його в `payload.zip`,
вбудовує архів в інсталятор. Результат у `artifacts\`:

| Файл | Призначення |
|---|---|
| `Installer.exe` | інсталятор (містить лаунчер і .NET, окремо нічого ставити не треба) |
| `launcher\MineCoreLauncher.exe` | лаунчер без встановлення |

Для розробки: відкрийте `MineCore.slnx` у Visual Studio, стартовий проєкт — `MineCore.Launcher`, F5.

## Інструкція з встановлення

1. Запустіть `Installer.exe`.
2. Оберіть папку (за замовчуванням `%LOCALAPPDATA%\Programs\MineCore Launcher`) і ярлики.
3. Перевірка системи виконується автоматично: версія Windows, вільне місце, права на запис.
4. Натисніть «Встановити», потім «Запустити MineCore».

Інсталятор не потребує прав адміністратора. Видалення — у «Параметри → Програми» або `Uninstall.exe /uninstall`
у папці встановлення. Світи, збірки й налаштування в `%APPDATA%\MineCore` при цьому залишаються.

## Структура проєкту

```
MineCore/
├── Installer/          інсталятор (WPF): перевірки, розпаковування, ярлики, запис у «Програми та засоби»
├── MineCore.Launcher/  лаунчер (WPF, MVVM): Views, ViewModels, Services, Themes — це «UI/» зі специфікації
├── Core/               шляхи, налаштування (JSON), локальна база (SQLite), HTTP
├── Minecraft/          маніфест версій Mojang, новини, сканер встановлених версій
├── Assets/             логотип та іконка
├── build.ps1
└── MineCore.slnx
```

Наступні бібліотеки додаються як окремі проєкти на своїх етапах:
`DownloadManager/`, `Authentication/`, `ModManager/`, `Modrinth/`, `CurseForge/`, `ModpackManager/`.

## Що вже працює (етап 1)

- Головне вікно з боковою панеллю з 9 розділів, темною темою, профілем унизу, масштабуванням і повноекранним режимом.
- Головна: список встановлених версій (читається з `<папка Minecraft>/versions`), кількість модів,
  інформація про вибрану версію, новини з контент-фіду Mojang, остання release і snapshot, історія запусків (SQLite).
- Версії: усі версії з офіційного маніфесту Mojang, пошук, фільтр за типом, позначка «Встановлено».
  Якщо мережі немає — використовується останній збережений кеш.
- Налаштування зберігаються в `%APPDATA%\MineCore\settings.json`, вибрана версія — між запусками.

Усе інше показує сторінку з етапом, на якому розділ буде реалізований. Кнопка «ГРАТИ» поки вимкнена.
